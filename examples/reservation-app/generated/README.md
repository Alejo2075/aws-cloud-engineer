# booking-app

Generated by [Cloud Engineer](https://github.com/Alejo2075/aws-cloud-engineer).
HTTP API (API Gateway) + Lambda + DynamoDB, with Cognito JWT authentication on every route.

## Entities

- **Booking** (`/bookings`): `guestName` (string, required), `partySize` (number, required), `date` (string, required)

Each entity exposes `GET/POST /<name>s` and `GET/DELETE /<name>s/{id}`. Items are scoped to the
authenticated Cognito user (`sub`).

## Commands

```bash
npm install
npm run typecheck && npm test   # unit + infrastructure assertions
npm run synth                   # build the Lambda bundle and synthesize the template
npm run deploy                  # deploys to your AWS account; review `cdk diff` first
```

Stage defaults to `staging`; use `npx cdk deploy -c stage=production` for production
(data and the user pool are retained on stack deletion in production only).

## Known limitations

- No frontend is generated for this template.
- Listing returns at most 100 items per entity and does not paginate.
